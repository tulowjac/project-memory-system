# Install

Copy this folder into an AI-tool workspace or reference it from a project instruction file.

For tools with native plugin support, prefer the target-specific installer:

```bash
python installers/install.py --target codex --dest <path>
python installers/install.py --target claude-code --dest <path>
python installers/install.py --target antigravity --dest <path>
python installers/install.py --target portable --dest <path>
```
